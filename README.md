### What I build

Business software that has to hold in production: multi-tenant data, permissions, billing, and tests that prove it.
Before building my own products, I spent two years in application support at Ariane Systems, between clients and the
development team. I still work that way: reproduce, fix, verify before it ships.

**[TraviXO](https://travixosystems.com)** · equipment tracking and VGP compliance for French rental companies.
I designed and built it alone. Between August and October 2026: a multi-tenant security audit with every critical
finding closed and evidenced, billing rebuilt around licensed asset capacity (Stripe, enforced in the database),
several agencies per account, a machine dossier PDF emailed at check-out, and per-person compliance alerts.
500+ commits in that period, 103 database migrations. Code is private; [case study here](https://github.com/theWQLker/Travixo-demo).

**[Deralis Digital](https://deralis.digital)** · my software practice for French SMEs. About a dozen working demos,
built in October 2026, each around one real workflow. All use fictional data and need no login.
